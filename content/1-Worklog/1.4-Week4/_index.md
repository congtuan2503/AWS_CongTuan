### Weekly Topic

Deploying Serverless Computing + Configuring API Gateways

### Weekly Objectives

* Manually write and deploy event-handling code to AWS Lambda.
* Publish RESTful APIs to interact with Lambda via API Gateway.

### Work Schedule

| Date | Day | Task Description | Lab / Project |
| :--- | :--- | :--- | :--- |
| 22/06/2026 | Monday | Understand the Serverless computing model on AWS. Read Lambda documentation. | [Module: Serverless](https://cloudjourney.awsstudygroup.com/) |
| 23/06/2026 | Tuesday | Write the first data processing function with AWS Lambda (Node.js/Python). Test logs on CloudWatch. | [Lab 07 - Lambda Function](https://cloudjourney.awsstudygroup.com/) |

| 26/06/2026 | Friday | Deploy API to a stage (dev/prod). Update week 4 worklog. | Progress Report |

### Expected Outcomes

* Lambda function runs stably, returning accurate results based on input.
* Public API endpoint is accessible externally and routes correctly to Lambda.
