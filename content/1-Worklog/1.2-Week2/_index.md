### Weekly Topic

Deploying VPC virtual network infrastructure + Launching EC2 virtual servers

### Weekly Objectives

* Manually build a complete VPC network with Internet connectivity.
* Successfully configure and SSH into an EC2 server, installing a basic web server.

### Work Schedule

| Date | Day | Task Description | Lab / Project |
| :--- | :--- | :--- | :--- |
| 08/06/2026 | Monday | Learn Amazon VPC virtual network architecture. Calculate and divide IP CIDR blocks. | [Module: Amazon VPC](https://cloudjourney.awsstudygroup.com/) |
| 09/06/2026 | Tuesday | Practice dividing Public and Private Subnets. Attach Internet Gateway for Public Subnet. | [Lab 03 - VPC Configuration](https://cloudjourney.awsstudygroup.com/) |
| 10/06/2026 | Wednesday | Research Amazon EC2 compute service and AMI types. | [Module: Amazon EC2](https://cloudjourney.awsstudygroup.com/) |
| 11/06/2026 | Thursday | Initialize Ubuntu server on EC2. Configure Security Group to open ports 22 and 80. | [Lab 04 - Launch EC2](https://cloudjourney.awsstudygroup.com/) |
| 12/06/2026 | Friday | SSH into the server to install Nginx/Apache. Test web access and summarize week 2. | Progress Report |

### Expected Outcomes

* VPC network operates smoothly with clear traffic routing.
* EC2 instance is successfully launched and hosts a basic HTML page.
